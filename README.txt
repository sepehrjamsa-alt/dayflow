DAYFLOW V4 — نسخه چهار

فایل‌ها:
- index.html: پوسته و قابلیت‌های اصلی نسخه V2
- v3.js: قابلیت‌های افزوده‌شده نسخه چهارم
- manifest.webmanifest: مشخصات نصب PWA
- sw.js: سرویس‌ورکر و کش نسخه چهارم
- icon.png: آیکون برنامه

حفظ اطلاعات نسخه قبل:
- کلید قدیمی df-events حفظ شده است؛ برنامه‌های ذخیره‌شده در V2 باید در V4 نیز قابل مشاهده باشند.
- پروفایل و تنظیمات V4 در کلیدهای جداگانه مرورگر ذخیره می‌شوند.
- برای اطمینان، پس از اولین اجرای V4 از بخش تنظیمات یک نسخه پشتیبان JSON بگیر و پیش از به‌روزرسانی‌های بعدی آن را ذخیره کن. هنگام جایگزینی V2 با V4، داده‌های سایت را پاک نکن؛ کلید df-events حفظ شده است.

قابلیت‌های V4:
- پروفایل محلی، نام نمایشی، پایه، ایموجی یا تصویر آواتار و رنگ اصلی
- داشبورد روزانه، پیشرفت، کلاس بعدی، تکالیف باقی‌مانده و فریز استریک
- دسته‌بندی‌های رنگی کلاس، تکلیف، شخصی و امتحان/رویداد
- نمایش هفتگی شنبه تا جمعه
- اولویت ضروری/معمولی/کم‌اهمیت و نمایش موارد عقب‌افتاده با امکان انتقال به امروز
- تکرار هفتگی کلاس‌ها با تولید جلسه‌های آینده؛ ویرایش یک جلسه یا تمام جلسات آینده؛ توقف سری
- تایمر تمرکز و آمار پایه
- دستیار منویی و سبک Daya؛ افزودن برنامه با فرم و نمایش برنامه امروز، فردا و هفته جاری
- خروجی کلاس‌ها به فایل ICS همراه هشدار ۳۰ و/یا ۶۰ دقیقه قبل برای واردکردن به Samsung Calendar
- پشتیبان‌گیری و بازیابی فایل JSON
- امضای سازنده

نکات مهم و محدودیت‌ها:
1) Daya در V4 دستیار دکمه‌ای و محلی است و از هوش مصنوعی آنلاین یا تحلیل جمله آزاد استفاده نمی‌کند. افزودن برنامه پس از بررسی ذخیره موفق تأیید می‌شود.
2) خروجی Samsung Calendar یک‌طرفه است. تغییرات بعدی DayFlow خودکار به تقویم سامسونگ منتقل نمی‌شود. پس از واردکردن فایل ICS، حتماً هشدارهای رویداد را در Samsung Calendar بررسی کن؛ رفتار هشدار به نسخه برنامه و تنظیمات دستگاه بستگی دارد.
3) اعلان‌های زمان‌بندی‌شده مرورگر تضمین نمی‌شوند وقتی مرورگر کاملاً بسته یا سیستم‌عامل اجرای پس‌زمینه را متوقف کرده باشد. اعلان‌های کلاس در Samsung Calendar راهکار مناسب‌تری برای یادآوری هنگام بسته بودن سایت هستند.
4) تایمر تمرکز تا وقتی صفحه باز است کار می‌کند.
5) اطلاعات در همان مرورگر و همان دستگاه می‌ماند. پاک‌کردن داده‌های سایت ممکن است اطلاعات را حذف کند؛ از نسخه پشتیبان استفاده کن.
6) فریز استریک حداکثر ۳ عدد نگه می‌دارد؛ به ازای هر ۷ روز فعال ثبت‌شده یک فریز جایزه داده می‌شود. فریز فعالیت جعلی ثبت نمی‌کند.
7) تکرار هفتگی در این نسخه همچنان به‌صورت جلسه‌های مستقل در df-events ذخیره می‌شود (۶ ماه پیش‌فرض، ۱ سال یا تا ۲ سال). این روش با ویرایش تک‌جلسه‌ای سازگار است، اما هنوز بهینه‌سازی کاملِ ذخیره‌سازیِ سری‌ها به‌صورت الگو انجام نشده است؛ سری‌های بسیار پرتکرار می‌توانند تعداد رویدادها را افزایش دهند.

به‌روزرسانی GitHub Pages:
1. ابتدا از اطلاعات DayFlow نسخه پشتیبان JSON بگیر.
2. فایل‌های همین ZIP را از حالت فشرده خارج کن.
3. در مخزن GitHub خود وارد پوشه اصلی سایت شو.
4. فایل‌های index.html، v3.js، sw.js، manifest.webmanifest و icon.png را در ریشه مخزن بارگذاری و نسخه‌های قبلی را جایگزین کن.
5. Commit changes را بزن و چند دقیقه برای انتشار GitHub Pages صبر کن.
6. سایت را دوباره باز کن. اگر نسخه قبلی دیده شد، صفحه را یک‌بار کامل بارگذاری یا مرورگر را ببند و باز کن؛ داده‌های سایت را پاک نکن.

توجه: این نسخه بر اساس فایل‌های موجود V2 توسعه داده شده است. قابلیت‌های مرورگر و واردکردن ICS در گوشی واقعی باید پس از انتشار روی همان دستگاه بررسی شوند.
