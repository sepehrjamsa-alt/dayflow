DAYFLOW v1 — نسخه آزمایشی

محتویات:
- index.html: برنامه اصلی
- manifest.webmanifest: مشخصات نصب PWA
- sw.js: سرویس‌ورکر پایه
- icon.svg: آیکون

ویژگی‌های فعلی:
- تقویم شمسی با نمایش ماه و روز
- افزودن، ویرایش، حذف و تکمیل برنامه‌ها
- دسته‌بندی کلاس، امتحان، تکلیف و شخصی
- چند گزینه یادآوری قبل از موعد
- ذخیره محلی در مرورگر
- تغییر زبان نمایشی فارسی/انگلیسی
- تنظیم مجوز اعلان و ساعت سکوت ۲۳ تا ۷

محدودیت مهم:
این نسخه نمونه اولیه است. اعلان‌های زمان‌بندی‌شده در این نسخه فقط تا وقتی صفحه باز و فعال است قابل اتکا هستند؛ سرویس‌ورکر پایه به‌تنهایی اعلان زمان‌بندی‌شده در پس‌زمینه را تضمین نمی‌کند. تکرار خودکار تکالیف در این نسخه فقط وقتی صفحه باز است کار می‌کند. صدای اعلان از تنظیم صدای پیش‌فرض اعلان‌های مرورگر/اندروید پیروی می‌کند و صدای اختصاصی هنوز پیاده‌سازی نشده است. برای اعلان قابل‌اعتماد در پس‌زمینه، مرحله بعد باید Push/Backend یا نسخه بومی اندروید و آزمایش روی دستگاه باشد.

برای نصب PWA:
فایل‌ها را روی یک میزبان HTTPS قرار بده، سپس در Chrome اندروید سایت را باز کن و از منوی سه‌نقطه گزینه Install app یا Add to Home screen را بزن.
